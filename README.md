# Real-time-chat-application

Real-Time WebSocket Chat Application

A dynamic, real-time chat application built with Spring Boot and WebSocket using the STOMP protocol. Users can join a chatroom, send messages, and receive instant updates for join, chat, and leave events. The backend leverages Spring’s WebSocket support with a simple message broker, while the frontend features an interactive UI powered by HTML, CSS, and JavaScript with SockJS and STOMP.js. This project demonstrates real-time communication, event-driven programming, and full-stack development.

Features:

Real-time messaging with JOIN, CHAT, and LEAVE events
User session management with STOMP session attributes
Responsive UI with colorful user avatars
Error handling for WebSocket connections
Technologies:

Backend: Spring Boot, Spring WebSocket, STOMP, Lombok, Maven
Frontend: HTML, CSS, JavaScript, SockJS, STOMP.js (Cloudflare CDN)
Tools: IntelliJ IDEA, Maven
How to Run:

Clone the repo: git clone <repo-url>
Install dependencies: mvn clean install
Run the app: mvn spring-boot:run
Access at http://localhost:8080
Learning Outcomes:

Mastered WebSocket and STOMP for real-time communication
Configured Spring Boot message brokers and controllers
Integrated frontend and backend for seamless messaging
Troubleshot dependency issues, 404 errors, and IntelliJ configurations
